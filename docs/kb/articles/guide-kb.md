## What this feature does

Guide opens this local Knowledge Base. PASS128 keeps a compact Guide anchor available when the window is narrow and the full Guide button moves into More Tools.

## How to use it

Use the KB for feature walkthroughs, screenshots, keyboard hints, and operator safety notes. The KB ships as static source and does not require an online service.

## Safety notes

- Keep secrets, tokens, cookies, runtime browser profiles, generated installers, and local data out of source.
- IT Docs and PSA references remain browser-side display/context unless a server-authorized workflow exists.
- Treat Mission files and exported evidence as untrusted until validated and redacted.


## PASS131 search note

The in-app KB now includes a local search panel and quick filters. Use it to find Mission Control, 3-Up, Quad View, Ctrl+K, Evidence, downloads, settings, and troubleshooting topics without sending any query to a server.
