# Open Source Release Plan

TAHAI Web Services Browser 1.8.0 is being prepared for public GitHub release.

- Source license: Apache-2.0
- Attribution: `NOTICE`
- Trademark handling: `TRADEMARKS.md`
- No generated release artifacts in source
- No secrets, provider keys, certs, profiles, caches, or runtime data
- CI validates source and build gates
- Installers are distributed through GitHub Releases or official TAHAI sites

Signing path: publish public source, preserve clean build separation, apply to SignPath Foundation, then add a signed release workflow after approval.
