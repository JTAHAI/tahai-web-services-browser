# Privacy Policy

TAHAI Web Services Browser is an open-source Chromium-compatible browser workbench.

## Summary

TAHAI Web Services Browser does not intentionally collect, sell, or transfer user telemetry, browsing history, credentials, or personal data to TAHAI Web Services.

The browser may store normal browser/application data locally on the user's device, such as preferences, local profile data, browser cache, cookies, history, session state, and downloaded files, depending on how the user operates the application.

## Network activity

This browser connects to websites, web applications, provider consoles, AI services, cloud services, and other network destinations specifically requested by the user or configured by the person installing or operating the software.

Third-party websites and services opened by the user are governed by their own privacy policies.

## Local data

Application settings, profile data, and browser state may be stored locally on the user's machine. Users can uninstall the application and remove local profile data using normal operating system controls.

## Official releases

Official TAHAI Web Services Browser releases are distributed through the public GitHub repository and official TAHAI Web Services download pages.
