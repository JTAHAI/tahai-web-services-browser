| Version | Supported |
| --- | --- |

## Reporting a vulnerability

Please do not post exploitable security issues publicly before TAHAI has had a
reasonable opportunity to review and respond.

Preferred reporting path:

1. Use GitHub private vulnerability reporting if enabled for this repository.
2. If unavailable, email: justintahai@gmail.com

Please include a description, affected version/commit, reproduction steps,
impact, and whether the issue requires local access, user interaction, network
access, or a malicious website.
