Distribution

The Microsoft Store is the official Windows distribution lane for TAHAI Web Services Browser.

Open Microsoft StoreInspect source

Release policy

Official package

The current official Windows package is distributed through the Microsoft Store listing linked from this website.

Historical installers

Old preview EXE, MSI, Linux test packages, checksums, and release manifests have been retired from the public website.

Open-source repository

The GitHub repository remains available for source inspection, issue reporting, and development. A locally built copy is not the same as the official Store package.

Release claims

TAHAI Web Services does not label a direct source build or third-party package as an official Microsoft Store release.
