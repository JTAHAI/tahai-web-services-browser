TAHAI Browser Profiles

Profiles

Profiles isolate cookies, sessions, storage, cache, permissions, and service login state.

This pass creates Chromium-style local profiles using separate Electron session partitions. Google/Microsoft labels are ready for account-centered workflows, but cloud account sync is intentionally not enabled yet.

TAHAI DevOps Evidence

Documentation-ready capture

Captures the active tab URL, title, visible page structure, basic timing, and a runbook-ready incident/change template. It intentionally avoids cookies, localStorage values, passwords, tokens, and form contents.

TAHAI IT / DevOps Diagnostics

URL operations check

Runs a safe HEAD request against the active URL, summarizes HTTP status and operational headers, and outputs a documentation-ready checklist for IT engineering, DevOps, QA, and support. It excludes cookies, authorization headers, request bodies, localStorage values, and form contents.

TAHAI DevOps Engineering

Deploy Readiness

Creates a deployment-ready Markdown report for release/change tickets, rollback planning, smoke checks, and post-deploy verification. It combines safe HTTP/header diagnostics, active-page context, load timing, and console error/warning counts. It excludes cookies, authorization headers, request bodies, response bodies, storage values, credentials, tokens, and form contents.

TAHAI IT Engineering Documentation

IT Service Card

Creates a documentation-ready service profile for the active URL with public DNS, safe HTTP headers, page context, ownership placeholders, access notes, monitoring/recovery fields, and TAHAI IT Docs handoff checks. It excludes cookies, authorization headers, request bodies, response bodies, storage values, credentials, tokens, and form contents.

TAHAI IT Engineering Support

Endpoint Snapshot

Creates a safe browser/client environment profile for helpdesk, endpoint troubleshooting, implementation notes, and TAHAI IT Docs handoff. It captures platform, language/timezone, screen/viewport, online state, permission states, storage availability booleans, and active URL context only. It does not read cookies, clipboard contents, storage values, passwords, tokens, local files, IP addresses, or form contents.

TAHAI IT Engineering Support

Support Triage

Creates a helpdesk-ready support/escalation packet from the active tab with safe page context, endpoint/browser signals, HTTP reachability, console error counts, impact fields, reproduction prompts, and escalation checklist. It excludes cookies, storage values, clipboard contents, passwords, tokens, local files, IP addresses, request bodies, response bodies, and form contents.

TAHAI IT Engineering Vault

Credential Manager

Credentials are encrypted with OS-backed Electron safeStorage and stored in the local app data profile.

This is a first-party local vault. It does not use Chrome Sync or a Chromium cloud password manager. Secrets are encrypted through Electron safeStorage before writing to disk.

TAHAI Evidence / Change Control

Bundle Composer

Builds a local Markdown bundle from pinned Evidence Timeline items, saved workspace snapshots, active profile context, and IT Docs / PSA handoff fields. It only includes evidence that was explicitly generated or pinned by the user. It does not collect cookies, storage values, credentials, tokens, request bodies, response bodies, clipboard contents, local files, or form values.

TAHAI Operational Handoff

IT Docs / PSA Handoff Center

Creates a focused operational handoff for TAHAI IT Docs today and TAHAI PSA ticket/change workflows when the PSA lane ships. It uses active profile context, current tabs, saved workspaces, and explicitly pinned evidence only.

TAHAI Ops Guard

Redaction Review

Reviews the latest bundle, handoff, or generated tool output before it leaves the browser. It flags likely secrets, credential terms, private keys, provider tokens, and share-risk markers, then creates a redacted copy for external tickets, emails, or vendor handoffs.

TAHAI Developer Engineering

Route Map

Creates a documentation-ready frontend route/API surface map from the active tab. It samples same-origin routes, external origins, forms by method/action, resource origins, framework hints, and API-like resource paths. It strips query strings/fragments and excludes cookies, storage values, credentials, tokens, request bodies, response bodies, form values, clipboard contents, and local files.

TAHAI Developer Engineering

Developer Audit

Creates a documentation-ready developer audit from the active tab: console warnings/errors, resource timing, load metrics, page structure, and lightweight quality checks. It strips query strings from resource URLs and excludes cookies, storage values, credentials, tokens, request bodies, response bodies, and form contents.
