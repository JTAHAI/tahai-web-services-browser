TAHAI Web Services Browser

Runtime settings

Settings are written under the local app data profile, never into this source repo. Defaults reset to https://tahaiportal.com.

PASS95: permission toggles are still origin-gated in the main process. Camera/microphone, clipboard-read, geolocation, and notification requests are denied unless the requesting page is HTTPS or localhost and the matching setting is enabled.

PASS96: download events are routed back to the trusted shell with sanitized filenames only. Local filesystem paths are hidden from renderer status updates, and executable/installer downloads are flagged before handoff. PASS97: mission, profile, and evidence-save handoffs return saved labels instead of local paths.

PASS99: Mission pane drops and Mission tab reorders accept only TAHAI internal drag payloads. External files, URLs, HTML, and text drops are blocked at the renderer shell boundary.

PASS100: active-page capture output from remote webviews is redacted, URL-normalized, size-capped, and origin-sanitized before preview, pinning, copy, save, or diagnostics handoff.

PASS101: runtime settings are size-capped and sanitized in the main process. Saved home pages must be HTTPS or localhost HTTP, and renderer settings never carry local download paths.

PASS103: Ops diagnostics use a cookie-free Node request boundary and are SSRF-guarded. Localhost, private/link-local ranges, metadata endpoints, single-label internal hosts, unsafe DNS results, and redirect targets are blocked or withheld automatically; diagnostic output never include Cookie or Authorization output.

PASS104: Remote page titles, status text, Mission timeline entries, and Mission metadata URLs are sanitized before renderer display or local Mission handoff, so hostile tab metadata cannot carry control characters, bidi spoofing, embedded credentials, or tokenized query strings into evidence.

TAHAI Browser Profiles

Profiles

Profiles isolate cookies, sessions, storage, cache, permissions, and service login state.

Profiles use separate Electron session partitions. Account labels are local-only; no Chrome Sync, browser cloud sync, PSA tokens, provider API keys, cookies, or OAuth refresh tokens are stored in TAHAI mission/profile metadata.

TAHAI DevOps Evidence

Documentation-ready capture

Captures the active tab URL, title, visible page structure, basic timing, and a runbook-ready incident/change template. It intentionally avoids cookies, localStorage values, passwords, tokens, and form contents. PASS93 copy/save actions run through a second main-process redaction boundary before clipboard or disk handoff. PASS97 hides local filesystem paths after saves. PASS100 sanitizes active-page capture output from remote webviews before preview, pinning, copy, or save.
