# TAHAI Web Services Browser Privacy Policy

TAHAI Web Services Browser does not intentionally collect, sell, or transfer user telemetry, browsing history, credentials, or personal data to TAHAI Web Services.

Normal browser and application data may be stored locally on the user's device, including preferences, profile data, cache, cookies, history, session state, mission data, evidence files, and downloads.

The browser connects to websites and services requested by the user. Third-party services are governed by their own privacy policies.

The official Windows distribution is available through the Microsoft Store. The public GitHub repository is provided for source review and development.
