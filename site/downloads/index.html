Native source

The Electron era is behind the active source.

The public repository now contains the native Chromium-based TAHAI browser. Development features, compatibility fixes, and locally built MSIX packages are not automatically part of the version currently distributed by the Store.

Use the version you actually installed.

Check your installed browser version when reporting issues. Source changes and website screenshots can be newer than the distributed package. Old Electron-era Windows previews and Linux test-package lanes are historical, not the current recommended installation path.
