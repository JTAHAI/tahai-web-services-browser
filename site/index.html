A few useful distinctions

Know what you are getting.

Is TAHAI still an Electron browser?

The active public source is the native Chromium-based TAHAI browser. The former Electron shell is not the current development foundation.

Does everything in GitHub ship in the Store release?

No. Source development can be ahead of the published package. Check the release information for the version you install; a website update does not certify a new browser build.

Where can I share feedback?

Use the browser's GitHub issues for reproducible bugs and workflow suggestions. Include your version and the steps to reproduce, but do not post credentials, private keys, customer data, or unsanitized browser profiles.
