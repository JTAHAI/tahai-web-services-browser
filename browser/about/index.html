Security posture

Mission files are treated as untrusted local input. IT Docs and PSA integrations remain browser-side references only; secrets, OAuth refresh tokens, PSA API keys, and cloud credentials do not belong in this open-source browser repo.

Defense in depth: validated links, narrow preload APIs, no direct PSA calls, redaction-aware exports, and explicit user action before sync or handoff.
