TAHAI Web Services Browser

Privacy Policy

TAHAI Browser is designed around local user control, user-requested browsing, and operational workflows.

Summary

TAHAI Web Services Browser does not intentionally collect, sell, or transfer user telemetry, browsing history, credentials, or personal data to TAHAI Web Services.

The browser may store normal application and browser data locally on the user’s device, including preferences, profile data, cache, cookies, history, session state, mission data, evidence files, and downloaded files, depending on how the software is used.

Network activity

The browser connects to websites and services requested by the user or configured by the operator. Third-party services are governed by their own privacy policies.

Local data

Settings and browser state may be stored locally. Users can remove the application and local data using normal operating-system controls.

Official distribution

The official Windows distribution is available through the Microsoft Store. The public GitHub repository is provided for source review and development.
